# Pocket Network를 한국 개발자에게 소개합니다

*Audience: Korean developers building AI agents, who have mostly not heard of Pocket. Korean text first, English translation below.*

## 한국어 (본문)

AI 에이전트에게 한국 데이터를 물리려고 하면 늘 같은 데서 막힙니다. 공공데이터포털 가입, 서비스마다 활용 신청, 인증키 발급, 그리고 XML 파싱입니다. 사람은 할 수 있지만 에이전트는 가입 양식을 채우지 못합니다.

Pocket Network의 Agentic Portal은 이 과정을 없앱니다. 계정도 API 키도 없습니다. 주소 하나를 호출하면 가격(호출당 0.005달러)이 돌아오고, 지갑으로 서명해 다시 보내면 JSON이 옵니다. 현재 120개 서비스가 같은 방식으로 열려 있습니다.

한국 데이터도 이미 있습니다. 아파트 실거래가, 전자공시(DART) 정정 이력, 관세청 10일 단위 수출 통계, 법령 조문, 기준금리와 환율을 한국어 질문으로 부를 수 있습니다.

반대 방향도 열려 있습니다. 누구나 자기 API를 서비스로 등록하고, 호출이 정산될 때마다 POKT로 보상을 받습니다.

시작은 이 한 줄이면 됩니다: https://agent.pocket.network/llms.txt

## English translation

Anyone who has tried to give an AI agent Korean data gets stuck at the same place: registering on the government data portal, applying for each dataset, waiting for a key, then parsing XML. A person can do that. An agent cannot fill in a signup form.

Pocket Network's Agentic Portal removes those steps. There is no account and no API key. You call one URL, it replies with the price ($0.005 per call), you sign with a wallet and resend, and JSON comes back. 120 services are open the same way today.

Korean data is already there: apartment sale records, corrections to DART filings, the customs service's 10-day export statistics, statute text, and base rates and exchange rates, all callable with a question in Korean.

It works in the other direction too. Anyone can register their own API as a service and is rewarded in POKT each time a call settles.

One link is enough to start: https://agent.pocket.network/llms.txt
