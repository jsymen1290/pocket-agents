# Discover What You Can Do With the Agentic Portal

Pocket Community Hub quest answer by jsymen.

1) KR Apartment Trades (https://agent.pocket.network/services/kr-apt-trades-v1): for proptech builders, researchers and AI assistants answering Korean housing questions. It returns actual apartment sale prices by district and month from the government register. Use case: an agent answering "what did 84㎡ units in Seocho sell for last month?" with official numbers instead of guesses.

2) Academic Literature Search (https://agent.pocket.network/services/literature-search): for research agents and RAG pipelines. It searches OpenAlex for academic works and returns metadata and abstracts. Use case: a literature-review agent that pulls the latest papers on a topic and cites them properly.

Sources: https://docs.pocket.network/
