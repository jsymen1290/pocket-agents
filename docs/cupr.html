Network parameters (editable)

Defaults were read from MainNet on 13 November 2026. They are governance parameters and can change, so check them before a decision:

pocketd query shared params --network main
pocketd query tokenomics params --network main
pocketd query service show-service <service-id> --network main

What this does not include

It is settlement arithmetic only. It leaves out gas for claims and proofs, your hosting and upstream costs, and the one-millionth global_inflation_per_claim. On busy services the relay count in a claim is an estimate from sampled relays, so real sessions vary slightly. It says nothing about token price.

A CUPR change applies from the next session, not to relays already served. Coordinate a change with the portal team if your service is listed there, because the portal's USD price has to cover what each call burns.
